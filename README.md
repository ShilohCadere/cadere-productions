# Cadere Productions

**Useful by design. Curious by nature.**

An independent curiosity studio building practical applications and imaginative interactive experiences. The studio presents selected works in progress with transparent stages rather than promising releases.

**Live website:** https://shilohcadere.github.io/cadere-productions/

## The collection

**Applications** — Practical software for real-world planning, comparison, and research:
- **Furlong** — Travel planning and scenario comparisons; in active development.
- **Weigh** — Decision-matrix concept.
- **Enough** — Research companion concept for evidence, uncertainty, and knowing when to stop.

**Experiences** — Digital places to investigate and explore:
- **Creature Cabinet** — Fictional natural-history archive; in design.
- **The Obsolescence Museum** — Future-facing collection of ordinary artifacts; in design.
- **The Town That Wasn’t** — Interactive mystery; in design.
- **Observatory of Everything** — Digital discovery space spanning scales; concept development.

Furlong is the most developed project. Its showcase uses the actual development interface with example data. Other project visuals are concept illustrations, not working application screenshots. Each project page identifies its stage.

## Editing and publishing

This is a static HTML/CSS/JavaScript site. Edit `index.html`, the individual project directories, and `assets/`. Preview with a local static HTTP server.

The site is designed for deployment at `/cadere-productions/` beneath the GitHub Pages user site. Keep its internal root-relative paths prefixed with `/cadere-productions/`. Publish from `main` → `/(root)` in GitHub Pages settings. Keep `.nojekyll` to prevent Jekyll processing.

Do not commit databases, credentials, secrets, or runtime session files. The Furlong product screenshot is based on seeded development data.
